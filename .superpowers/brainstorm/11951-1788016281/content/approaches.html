Abordagens para implementação

3 opções de como unificar os campos

Abordagem 1: Reutilizar searchQuery
• Usa o mesmo estado `searchQuery`
• Busca enquanto digita
• "Adicionar" cadastra o texto como item

Simples: reutilizar searchQuery

Mínima mudança de código. Pode confundir se usuário vê resultados de busca mas quer adicionar.

Abordagem 2: Novo estado inputValue
• Novo estado `inputValue` para o campo
• `searchQuery` só é atualizado com debounce
• Mais claro: separa busca de adição

Claro: novo estado inputValue

Mais código, mas mais flexível. Busca e adição ficam separados internamente.

Abordagem 3: Modo dual
• Indicador visual (cor/ícone) do modo atual
• Busca: ícone lupa azul | Adição: ícone + verde
• Mais intuitivo, mas mais complexo

Intuitivo: modo dual

Indicador visual do modo. Mais trabalho, mas experiência mais clara.

Recomendação

Abordagem 2 (Recomendada)

  • Equilíbrio entre simplicidade e clareza
  • Não confunde o usuário com resultados de busca
  • Código mais organizado

Abordagem 1 (Mais simples)

  • Pouca mudança de código
  • Pode confundir o usuário

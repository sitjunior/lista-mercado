Design Final: Campo Unificado

Abordagem 2: Novo estado inputValue

Componente GroceryList - Campo Unificado
Estado 1: Campo vazio (só busca)
Estado 2: Campo com texto (busca + adição)
• Busca envia `searchQuery` com debounce 300ms
• "Adicionar" cadastra "Arroz" como novo item
Estado 3: Botão X para limpar
• X limpa o campo e remove resultados de busca
• Adiciona `searchQuery` ao limpar

Fluxo de dados

Estados e transições
inputValue → estado do campo (o que o usuário digita)
searchQuery → estado da busca (atualizado com debounce)
1. Usuário digita → inputValue atualiza
2. Debounce 300ms → searchQuery = inputValue
3. Clica "Adicionar" → addItem(inputValue)
4. Após adicionar → inputValue = ''

Mudanças no código

Adições

  • Novo estado: inputValue
  • Botão "Adicionar" condicional
  • Função handleAdd() separada

Remoções

  • Campo "Novo item" inteiro
  • Estado newName
  • Borda tracejada
